## 📜 **Setup und Installation**
1. Klone das Repository:
   ```bash
   git clone https://github.com/DerLippo/Portfolio.git
   cd Portfolio
   ```
2. Installiere die Abhängigkeiten:
   ```bash
   npm install
   ```
3. Starte den Entwicklungsserver:
   ```bash
   npm start
   ```
